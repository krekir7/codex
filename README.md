# M-VAVE Audio Deck 1.3.1

[Скачать приложение для Windows (ZIP, 1,5 МБ)](https://github.com/krekir7/codex/raw/refs/heads/main/MVAVE_Audio_Deck_v1_3_1_Volume_Fix.zip)

В архиве: готовый EXE, исходники, исходные звуки, инструкция на русском и результаты проверок.

1. Завершите прежнюю версию Audio Deck через меню значка в трее → Выход.
2. Сохраните копию папки `%APPDATA%\MVAVE Audio Deck`.
3. Распакуйте весь ZIP в отдельную папку и запустите `START.cmd`.

Нужна Windows 10/11 с .NET Framework 4.8. Права администратора не требуются.

Обновлено оформление микшера и саундборда; добавлены звуковые площадки, горячие клавиши, автосохранение и восстановление настроек; оптимизирована обработка MIDI.

В 1.3.1 исправлено управление громкостью: поиск и регулировка приложений на всех активных аудиовыходах, обработка успешных статусов многопроцессных сессий, повтор команд после временной ошибки и повторное применение того же значения после внешнего изменения громкости.

После запуска включите песню в Яндекс Музыке, нажмите «Обновить приложения», выберите её процесс и проверьте фейдер мышью и MIDI. Если проблема осталась, запустите `CHECK_AUDIO.cmd`: он сохранит `AUDIO_DIAGNOSTICS.txt` без изменения громкости.

Сборка и 133 проверки выполнены в Linux через Mono/Xvfb. Аудиооперации и COM-сессии в тестах заменены управляемыми/нативными тестовыми заглушками. Реальные MIDI, Windows Core Audio/MCI, трей Windows и Discord в этой среде не проверялись.

Контрольная сумма архива находится в `SHA256.txt`.
